# SimCSE Reproduction — Final Scientific Synthesis

## Executive conclusion

This project successfully validates the core implementation of unsupervised
SimCSE and completes the planned reduced-data scaling study, controlled
dropout/temperature ablations, and alignment/uniformity analysis.

The evidence supports a mechanism-level conclusion: **SimCSE performance is
not explained by uniformity or alignment in isolation. The strongest results
occur when stochastic dropout produces useful positive-pair variation while
the learned representation maintains an effective alignment–uniformity
balance.**

## 1. Main empirical results

| Experiment | Training size | STS-B |
|---|---:|---:|
| Raw BERT CLS | 0 | 30.18% |
| SimCSE | 10K | 53.55% |
| SimCSE | 25K | 62.59% |
| SimCSE | 50K | 69.07% |
| No dropout | 50K | 60.21% |
| Fixed dropout mask 0.10 | 50K | 41.07% |
| Standard dropout 0.20 | 50K | 76.38% |
| Temperature 0.01 | 50K | 68.88% |
| Temperature 1.00 | 50K | 58.33% |
| Official pretrained SimCSE, local evaluation | — | 82.12% |

The 10K→25K→50K curve is monotonically improving:

- 10K: 53.55%
- 25K: 62.59%
- 50K: 69.07%

The incremental gains decrease from +9.04 pp to +6.48 pp. This is an
observed diminishing-return pattern over the tested range, not a universal
scaling law.

## 2. Dropout is a mechanism, not merely a hyperparameter

The completed dropout experiments provide the clearest causal evidence in
the project:

- No dropout: 60.21%
- Fixed shared mask at 0.10: 41.07%
- Independent standard dropout at 0.20: 76.38%

The fixed-mask condition is especially informative because it preserves a
nominal dropout rate while removing the independent stochastic perturbation
between views. Its poor result therefore supports the interpretation that
**view diversity generated by independent dropout is central to unsupervised
SimCSE**.

## 3. Temperature matters

The temperature experiments show:

- τ=0.01: 68.88%
- τ=1.00: 58.33%

The baseline τ=0.05 remains the main reproduction configuration. The result
demonstrates that contrastive-logit sharpness materially affects downstream
sentence similarity.

## 4. Representation geometry

The completed geometry measurements are:

| Experiment | STS-B | Alignment ↓ | Uniformity ↓ |
|---|---:|---:|---:|
| Raw BERT | 30.18% | 0.1771 | -1.0560 |
| SimCSE 50K | 69.07% | 0.2924 | -2.5705 |
| No dropout | 60.21% | 0.4486 | -2.7144 |
| Fixed mask 0.10 | 41.07% | 0.4057 | -2.3718 |
| Dropout 0.20 | 76.38% | 0.1946 | -2.3814 |
| Temperature 0.01 | 68.88% | 0.1642 | -1.5738 |
| Temperature 1.00 | 58.33% | 0.1030 | -1.9329 |

Lower is better for both geometry metrics.

### Key observation

The no-dropout model has the strongest uniformity in this local set
(-2.7144), yet its STS-B is only 60.21%. Therefore:

> **Uniformity improvement alone is not sufficient for good sentence
> similarity performance.**

Temperature 1.00 has the strongest alignment (0.1030), yet its STS-B is only
58.33%. Therefore:

> **Alignment improvement alone is also not sufficient.**

The standard-dropout 0.20 model provides the strongest local STS-B result
(76.38%) with alignment 0.1946 and uniformity -2.3814, illustrating the
importance of a useful balance.

The seven-point dataset is too small for a meaningful inferential correlation
claim. Descriptively, Spearman correlation between STS-B and alignment is
0.071, and between STS-B and uniformity is -0.536.
These values should **not** be interpreted as causal or statistically
reliable estimates.

## 5. Correct interpretation of the paper reference

The published SimCSE BERT-base result of 76.25% is the **average across seven
STS datasets**, not STS-B alone. In the paper table, STS-B is 76.85% and the
seven-task average is 76.25%.

Therefore, the local 76.38% STS-B ablation must **not** be described as
"beating the paper's 76.25% result." Those metrics are different.

Likewise, the locally evaluated official pretrained checkpoint score of
82.12% is a local STS-B validation result and is useful as a pipeline/model
reference, but is not numerically equivalent to the published seven-task
average.

## 6. Reproduction discrepancy

The main remaining difference from the official training protocol is
selection/evaluation behavior.

The official repository describes evaluating on STS-B during training and
saving the best checkpoint. The local CPU experiments instead trained one
epoch and evaluated the resulting epoch checkpoint.

The official project also reports its released unsupervised BERT model at
76.25 average STS and states that it used 1M Wikipedia sentences. The local
study intentionally uses 10K/25K/50K subsets because full 1M-sentence CPU
training was impractical.

These are protocol/resource differences, not evidence of a broken core
implementation.

## 7. What has been reproduced

### Strongly established

- BERT-base encoder and CLS representation
- Two stochastic views of the same sentence
- Independent dropout mechanism
- CLS + MLP during training
- Raw CLS evaluation when `mlp_only_train=true`
- Temperature-scaled cosine contrastive loss
- AdamW optimization
- Linear learning-rate scheduling
- Gradient clipping
- Complete checkpoint state
- Deterministic resume
- Full STS-B validation evaluation
- Reduced-data training behavior
- Dropout mechanism ablations
- Temperature ablations
- Alignment/uniformity geometry

### Not established

- Full 1M-sentence CPU training completion
- Exact paper-scale benchmark reproduction
- A universal training-data scaling law
- Causal proof from alignment/uniformity metrics alone

## 10. Final limitations

1. The main local training study is reduced-data because of CPU constraints.
2. The 1M run was launched but not completed.
3. The local training protocol does not reproduce every aspect of the
   official best-checkpoint selection procedure.
4. Only STS-B was locally evaluated for the completed reduced-data models;
   the published SimCSE number is a seven-task average.
5. Geometry conclusions are descriptive because only seven completed geometry
   conditions are available.
